// COLLECTOR CARD GENERATOR

This tool generates a randomised character as a collector card -- complete with rarity, holographic effects, and an assembled prompt ready to use in Stable Diffusion.

Each PULL rolls a new character with randomised race, appearance, outfit, and scene. The assembled positive and negative prompts are displayed below the card and can be copied with a single click.

The rarity system affects card visuals and prompt quality. Common cards get a clean result. Legendary cards get cinematic lighting, atmospheric depth, and an ornate collector frame -- all baked into the prompt.

Toggle SFW / NSFW in the header to unlock a wider outfit pool and more explicit prompt tags. The negative prompt updates automatically to match.

The background scene is weighted by race and refined by outfit -- an Elf in Fantasy Robes gets a moonlit elven grove with floating scrolls. A Vampire in a Gothic outfit gets a candlelit dungeon or baroque ballroom.

This is a v3 prototype -- the full version will be integrated into the WolfPack OC Builder as a modal pull system with character saving.
