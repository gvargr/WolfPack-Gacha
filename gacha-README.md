# WolfPack // Gacha

**Live:** https://gvargr.github.io/WolfPack-Gacha/

A randomised anime character collector card generator with holographic effects and Stable Diffusion prompt output.

---

## Features

- **Weighted random rolls** across 13 stat categories -- Race, Hair Colour, Hair Style, Eyes, Physique, Bust/Chest, Thighs/Legs, Hips/Build, Skin, Expression, Outfit, Accessory, Scene
- **Rarity system** -- Common / Uncommon / Rare / Epic / Legendary with weighted probability (50/25/15/7/3%)
- **Holographic card effects** -- rainbow foil, passive shimmer sweep, mouse-tracking shine and tilt, corner gems, star strip
- **Background weighting** -- scene is chosen by race and refined by outfit (Elf + Fantasy Robes → moonlit elven grove with floating scrolls)
- **Rarity quality tags** -- prompt quality boosters scale with rarity up to `(masterpiece:1.4)` for Legendary
- **Collector border frame** -- border tag included in prompt, scales from simple border to legendary gilded frame
- **SFW / NSFW toggle** -- separate outfit pools and prompt tags, negative prompt updates automatically
- **Futanari roll (Waifu NSFW only)** -- 15% probability, boosts rarity one tier, shown as card badge and stat row
- **Copy Prompt / Copy Neg** -- clipboard copy with HTTP fallback for local serving
- **Save Card** -- downloads the card as a PNG image drawn natively on Canvas (no external dependencies, works offline)

## Usage with Stable Diffusion

1. Open `index.html` -- flip the coin to go to Waifu or Husbando
2. Toggle SFW/NSFW as desired
3. Click **PULL** to generate a character
4. Re-roll as many times as you like
5. Click **COPY PROMPT** and paste into your SD interface (SwarmUI, A1111, ComfyUI, Forge)
6. Click **COPY NEG** and paste into the negative prompt field
7. Click **SAVE CARD** to download the card as a PNG
